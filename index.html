Background

I delivered this new module to our MEng Year 4 students, at Masters level, between October 2025 and mid-January 2026. This was a limited capacity, elective, and selective module, with 32 students on the course. Students formed 8 groups of 4 and produced 8 individual designs. Students used Cadence tools throughout, including Genus for synthesis, Innovus for placement and routing, Virtuoso for layout editing and viewing, Xcelium for simulation, Calibre for verification, and Modus for design-for-test and ATPG. All 8 chips were designed for TSMC 65nm CMOS low power process. Each team was provided with a custom designed PLL operating with a 25MHz external clock and a maximum internal clock frequency of 300MHz. Available silicon area is 1mm x 1mm in a 44 pin JLCC packaging. All chips were designed to be easily testable via a purpose-designed test rig hooked up to one or two FPGA boards (which drive and/or emulate the chip under test). The following pages provide brief descriptions and the layout for all 8 designs. All eight designs have been taped out at the end of February via EuroPractice/IMEC. The fabricated chips are returned to us at the beginning of June for testing. A one-day seminar will be held on June 18th 2026 when each team will present their design and the test results.

Team 1 - ARIA

This design accelerates ML inference using a custom RISC-V architecture with vector extensions. It features a five-stage CPU core where a scheduler maximizes throughput by parallelizing vector instructions. The system relies on compiler optimizations to reduce hardware complexity while supporting multi-precision arithmetic and a hierarchical memory structure.



Team 2 - NAND Technology

This project implements a custom RV32IMF RISC-V processor featuring a dedicated IEEE 754 FPU and hardware-accelerated AES-128 encryption. It integrates peripherals like UART and GPIO via a Wishbone bus, supported by dual-port memory and a JTAG interface for programming and debugging.



Team 3 - Hash Brown

Hash Brown is a 250 MHz Harvard Architecture SoC pairing a custom RV32I core with a hardware SHA-256 accelerator. It utilizes an AHB bus to connect tightly-coupled instruction and data memories, plus UART and SPI interfaces, designed to accelerate software-based cryptographic processing.



Team 4 - MOSAIC

MOSAIC is an edge-AI SoC pairing a PicoRV32 RISC-V CPU with a configurable matrix-multiplication accelerator. Designed for efficient preprocessing, it utilizes a unified 8 KB SRAM and DMA-driven architecture to minimize data movement and CPU overhead during small-scale linear algebra workloads.



Team 5 - HENRY

This project implements a custom CNN Accelerator for MNIST digit classification capable of processing 28x28 grayscale images. It features a hardware-optimized inference pipeline with dual parallel processing engines.



Team 6 - Cryptonite

Cryptonite is a secure RISC-V SoC that integrates a hardware AES-128 accelerator to encrypt instruction memory and decrypt it on-the-fly. A custom fetch controller manages key injection, stalls the CPU during decryption, and wipes plaintext memory, ensuring strict code confidentiality and protection against unauthorized access.



Team 7 - N-body Gravity Simulation Engine

This ASIC accelerates 3D N-body gravity simulations by offloading O(n^2) pairwise force calculations to a custom hardware design. It utilizes a tile-based processor architecture backed by on-chip SRAM to compute particle interactions in parallel, streaming updated coordinates via SPI for real-time visualization.



Team 8 - GEMM

This project implements a hardware-software codesign for General Matrix Multiply (GEMM) using a fixed-size systolic array. It features a Wishbone-connected accelerator that processes tiled sub-matrices, backed by on-chip SRAM and a host CPU to manage arbitrary matrix sizes via firmware.
